# Media kit – jak go opublikować

Strona trafi pod adres **https://sky-diverka.github.io/mediakit/**, obok Twojego linktree.

## 1. Uzupełnij przed publikacją

Otwórz `mediakit/index.html` w edytorze tekstu (np. TextEdit w trybie zwykłego tekstu albo VS Code).

- **E-mail:** ustawiony (skydiverka6@gmail.com). Żeby go zmienić, wyszukaj `data-email=` w `index.html`.
- **Viking:** jeśli nie możesz jeszcze pokazać tej współpracy, usuń linię z `<b>Viking</b>`.

## 2. Wrzuć na GitHub (przez przeglądarkę)

1. Wejdź na github.com i otwórz repozytorium **sky-diverka.github.io** (to, w którym jest linktree).
2. Kliknij **Add file → Upload files**.
3. Przeciągnij **cały folder `mediakit`** z `Biurko/Insta/MEDIA_KIT/` (folder, a nie pojedyncze pliki, żeby zostały podfoldery `img/`).
4. Na dole kliknij **Commit changes**.
5. Poczekaj 1–2 minuty i otwórz https://sky-diverka.github.io/mediakit/

## 3. Udostępnianie

- Link po polsku: `https://sky-diverka.github.io/mediakit/`
- Link od razu po angielsku (dla zagranicznych marek): `https://sky-diverka.github.io/mediakit/?lang=en`
- Strona sama wybiera język z ustawień przeglądarki, a gość może go przełączyć przyciskiem PL/EN.

## 4. Aktualizacja statystyk

Liczby są z Instagram Insights z 24.10.2026 (ostatnie 90 dni). Żeby je odświeżyć, w `index.html` zmień wartości `data-count="…"` w sekcji `STATS`, liczby w hero (`chips`) i datę w stopce. Potem wrzuć plik ponownie tak samo jak w kroku 2.
